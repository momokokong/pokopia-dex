## 🇹🇼 中文

**Pokopia 三語寶可夢圖鑑** — 給小朋友用的寶可夢圖鑑語言學習機！

用寶可夢的魅力，讓孩子在探索圖鑑的同時自然學習中文、英文和西班牙文。支援掃描 QR Code 或貼上進度碼跨裝置同步，不用帳號、不用登入，簡單好用。

### ✨ 功能

- 📖 **三語圖鑑** — 中文、英文、西班牙文即時切換，也可開啟三語同時顯示模式
- 🏝️ **棲息地瀏覽** — 按寶可夢棲息地分類探索
- 🎤 **語音朗讀** — 每隻寶可夢名稱三語發音，支援語速調整
- 🏅 **徽章系統** — 收集寶可夢解鎖成就徽章
- 🔗 **進度碼同步** — 產生 QR Code 或文字碼，在另一台裝置掃描/貼上即可同步收藏進度
- 💾 **JSON 匯出/匯入** — 完整備份與還原
- 📱 **離線 PWA** — 安裝後可離線使用

### 🛠️ 技術

純靜態網頁，無後端需求。使用 localStorage 儲存資料。

| 技術 | 用途 |
|------|------|
| Vanilla JS | 應用邏輯 |
| CSS Custom Properties | 主題與響應式設計 |
| Service Worker | 離線快取 (PWA) |
| QRCode.js | QR Code 生成 |
| PokéAPI | 寶可夢資料來源 |

### 🚀 使用方式

1. 開啟 `index.html` 或部署到任何靜態網頁伺服器
2. 點選寶可夢卡片收藏
3. 到「設定」頁面產生進度碼，在另一台裝置掃描/貼上同步

## 🇺🇸 English

**Pokopia Trilingual Pokédex** — A Pokédex language learning app designed for kids!

Harness the appeal of Pokémon to help children naturally learn Chinese, English, and Spanish while exploring the Pokédex. Sync your collection across devices with a QR code or progress code — no account, no login, just simple and fun.

### ✨ Features

- 📖 **Trilingual Pokédex** — Switch between Chinese, English, and Spanish; or enable trilingual mode to see all three at once
- 🏝️ **Habitat Explorer** — Browse Pokémon by their habitats
- 🎤 **Voice Pronunciation** — Hear each Pokémon's name in all three languages, with adjustable speed
- 🏅 **Badge System** — Collect Pokémon to unlock achievement badges
- 🔗 **Progress Code Sync** — Generate a QR code or text code, then scan/paste on another device to sync your collection
- 💾 **JSON Export/Import** — Full backup and restore
- 📱 **Offline PWA** — Install for offline use

### 🛠️ Tech

Pure static site, no backend required. Data stored in localStorage.

| Tech | Purpose |
|-----|---------|
| Vanilla JS | App logic |
| CSS Custom Properties | Theming & responsive design |
| Service Worker | Offline caching (PWA) |
| QRCode.js | QR code generation |
| PokéAPI | Pokémon data source |

### 🚀 Getting Started

1. Open `index.html` or deploy to any static web server
2. Tap Pokémon cards to collect them
3. Go to Settings → Generate a progress code, then scan/paste on another device to sync

## 🇪🇸 Español

**Pokédex Trilingüe de Pokopia** — ¡Una aplicación de Pokédex para que los niños aprendan idiomas!

Aprovecha el encanto de Pokémon para que los niños aprendan chino, inglés y español de forma natural mientras exploran el Pokédex. Sincroniza tu colección entre dispositivos con un código QR o código de progreso — sin cuenta, sin inicio de sesión, simple y divertido.

### ✨ Funciones

- 📖 **Pokédex trilingüe** — Cambia entre chino, inglés y español; o activa el modo trilingüe para ver los tres a la vez
- 🏝️ **Explorador de hábitats** — Navega los Pokémon por sus hábitats
- 🎤 **Pronunciación en voz** — Escucha el nombre de cada Pokémon en los tres idiomas, con velocidad ajustable
- 🏅 **Sistema de insignias** — Colecciona Pokémon para desbloquear insignias de logro
- 🔗 **Sincronización por código** — Genera un código QR o texto, luego escanea/pega en otro dispositivo para sincronizar
- 💾 **Exportar/Importar JSON** — Respaldo y restauración completa
- 📱 **PWA sin conexión** — Instala para usar sin internet

### 🛠️ Tecnología

Sitio estático puro, sin servidor backend. Datos guardados en localStorage.

| Tecnología | Uso |
|-----------|-----|
| Vanilla JS | Lógica de la app |
| CSS Custom Properties | Diseño responsivo y temas |
| Service Worker | Caché sin conexión (PWA) |
| QRCode.js | Generación de códigos QR |
| PokéAPI | Fuente de datos de Pokémon |

### 🚀 Cómo empezar

1. Abre `index.html` o despliega en cualquier servidor web estático
2. Toca las tarjetas de Pokémon para coleccionarlas
3. Ve a Configuración → Genera un código de progreso, luego escanea/pega en otro dispositivo para sincronizar
